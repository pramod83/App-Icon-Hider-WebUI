# App Icon Hider (WebUI)
**Created by Pramod kumar**

A lightweight, universal Magisk / KernelSU / APatch module with a built-in WebUI to hide or unhide app icons from your home screen and app drawer while keeping background services (such as Google Assistant, Gemini, Magisk) running smoothly.

## Features
- **True Icon Hiding:** Disables only the app's launcher activity, keeping background notifications and services active.
- **Boot Persistence:** Automatically keeps selected apps hidden even after a device reboot.
- **Auto-Restore on Uninstall:** Uninstalling the module cleanly restores all hidden app icons.
- **Universal Compatibility:** Works on Android 10 through Android 16/17 (OxygenOS, OneUI, HyperOS, Pixel, AOSP).

## Usage
1. Flash the ZIP in Magisk, KernelSU, or APatch and reboot.
2. Open KernelSU / APatch WebUI or the **KsuWebUI** app (ensure Root permission is granted).
3. Tap **App Icon Hider (WebUI)** and toggle any app icon on or off.
